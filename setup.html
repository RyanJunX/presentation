让电脑与手机使用同一份讲稿

网页已经连接你的 Supabase 项目。完成以下一次性配置后，就可以登录并同步。

1. 创建数据表与私有访问规则

点击下方“复制 SQL”，打开 Supabase SQL Editor，粘贴代码并点击右下角 Run。成功结果通常显示 Success. No rows returned。

也可下载 SQL 文件后打开复制。脚本带有权限与版本冲突检查，检查失败会回滚整次设置。

2. 创建你自己的登录账号

打开 Supabase 左侧 Authentication → Users，点击 Add user → Create new user。填写自己的邮箱和密码，勾选 Auto Confirm User 后创建。这个密码用于提词器登录，不是数据库密码；不需要把密码发送给任何人。

电脑和手机在提词器里填写相同的邮箱与密码。

3. 配置登录返回地址

打开 Authentication → URL Configuration，将 Site URL 设置为：

https://ryanjunx.github.io/presentation/presenter_script.html

在 Redirect URLs 中也添加这个完整地址并保存。密码登录无需邮件；若要使用邮箱登录链接，需要项目已配置可用的邮件发送服务。

4. 将电脑里的讲稿上传一次

  1. 如果旧 HTML 已有你的讲稿，先在旧文件中进入编辑模式并导出 JSON。
  2. 打开在线提词器，点击“登录 / 云同步”，用刚创建的账号登录。
  3. 导入旧 JSON，或直接编辑新的讲稿。
  4. 在“云同步设置”中点击“将当前讲稿保存到云端”。等待顶部显示“云端已同步”。
  5. 手机打开同一网址，登录同一邮箱；即可读取电脑上传的讲稿。

手机翻页、计时和字体独立设置。每 15 秒、页面重新打开或回到前台时会检查更新，也可以手动点“同步”。网络异常时讲稿继续保存在本设备。
